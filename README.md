# 游戏工具箱

一套纯前端的游戏/运动工具集合，适合线下聚会、球赛等场景使用。

页面使用原生 `HTML + CSS + JavaScript` 编写（篮球统计页面使用了 Vue 2 + Element UI），不需要打包构建，直接打开即可使用，部署到 GitHub Pages 也很方便。

## 功能模块

### 积分计算器

适合多人线下对局后快速核对输赢、抽水和转账方案。

- 支持动态添加和删除玩家
- 录入每位玩家的取分和剩余积分
- 支持设置抽水/场地费
- 支持指定场地费收款人
- 自动计算每位玩家输赢结果
- 自动校验数据是否平衡
- 自动生成结算明细和简化转账方案
- 支持生成测试数据，方便演示和自测
- 使用 `localStorage` 自动保存当前页面数据

### 比赛数据统计

篮球比赛数据记录与统计面板，支持实时记录比赛数据并保存到云端。

- 新建比赛（地点、时间、对阵信息）
- 球员管理（添加、删除、上场/休息切换）
- 实时记录得分（2分/3分/罚球）、篮板、助攻、盖帽、抢断、犯规
- 比赛计时与球员上场时长统计
- 对手总分记录
- 数据修正模式（直接编辑表格数据）
- 比赛结束后核对数据再保存到云端
- 历史比赛记录查询（支持日期范围筛选）
- 球员数据深度统计（月度统计 + 生涯总计）
- 使用 `localStorage` 自动保存未完成比赛，防止意外丢失

## 本地使用

### 直接打开

在浏览器中打开 `index.html`，通过导航页进入各功能模块。

也可以直接打开对应页面：

- `integral.html` — 积分计算器
- `matchStatistics.html` — 比赛数据统计

### 积分计算器使用流程

1. 输入抽水总额
2. 选择场地费由谁统一收取
3. 为每位玩家填写姓名、取分和剩余积分
4. 页面会自动计算输赢结果
5. 查看结算统计、校验状态和转账方案

### 比赛数据统计使用流程

1. 点击「添加球员」录入球员信息
2. 点击「新建比赛」填写比赛地点、时间和对阵信息
3. 选择上场球员后点击「开始比赛」
4. 比赛过程中选择球员并点击对应操作按钮记录数据
5. 比赛结束后点击「结束比赛」，核对数据无误后点击「保存比赛」
6. 在「历史记录 & 统计」中查看历史比赛和球员统计

## 数据保存说明

两个页面都使用浏览器的 `localStorage` 自动保存当前数据：

- 刷新页面后数据通常会保留
- 同一台设备上的同一浏览器可以继续使用上次数据
- 不同设备之间不会自动同步数据
- 清除浏览器缓存后数据可能丢失

比赛数据统计页面额外支持将比赛数据保存到云端服务器，保存后可在任意设备查看历史记录和统计报表。

## GitHub Pages 部署

这个项目是纯静态页面，适合直接部署到 GitHub Pages。

1. 将项目推送到 GitHub 仓库
2. 打开仓库页面，进入 `Settings`
3. 点击左侧 `Pages`
4. 在 `Build and deployment` 中选择：
   - `Source`：`Deploy from a branch`
   - `Branch`：`main`
   - `Folder`：`/ (root)`
5. 保存设置，等待部署完成

部署完成后，通常可以通过下面的地址访问：

```text
https://你的用户名.github.io/仓库名/
```

> 注意：比赛数据统计页面依赖后端 API 服务，GitHub Pages 仅部署前端页面，API 服务需要另行部署。
